# Bump (Bump Technologies)

> DEFUNCT. Bump Technologies (Mountain View, CA, 2008-2014) made Bump, an iOS and
> Android app that transferred contacts, photos and files between two phones bumped
> together, plus a first-party developer API and SDKs that embedded the same
> proximity-matching handshake in third-party apps. Bump was acquired by Google on
> 2013-09-16; the apps and the developer API were discontinued on 2014-01-31.
> There is no live Bump API, no developer portal, no documentation and no support
> channel. Do not attempt to integrate. This record exists so agents can resolve the
> name and stop, rather than chase dead endpoints.

## Status

- Company status: acquired (Google, 2013-09-16), product and API retired 2014-01-31
- API surface: none
- Homepage http://bu.mp/ returns 200 and serves only a shutdown notice: "Bump is no longer available."
- bu.mp serves HTTP only (no HTTPS), no DNSSEC, no CAA, no DMARC
- /.well-known/security.txt, /.well-known/api-catalog, /.well-known/openid-configuration and /llms.txt all return 404 on bu.mp
- No first-party packages on npm, PyPI, Maven Central, NuGet, RubyGems, Packagist, crates.io or pkg.go.dev
- Backed by Y Combinator, Sequoia Capital, and a $16M Series B led by Andreessen Horowitz (2011-01)
